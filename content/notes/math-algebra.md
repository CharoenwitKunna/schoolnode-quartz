# Algebra Basics

Algebra uses letters (variables) to stand for unknown numbers.

## Core skills
- Simplify: 2x + 3x = 5x.
- Solve: 2x + 6 = 14 → 2x = 8 → x = 4.
- Factorise: x² + 5x + 6 = (x + 2)(x + 3).
- Rearrange formulas: v = u + at → a = (v − u) / t.

Formulas like v = u + at come straight from [[physics-motion]] — learn them there, practise solving them here.
Stoichiometry in [[chemistry-bonds]] is just ratios, same skill as solving proportions.
